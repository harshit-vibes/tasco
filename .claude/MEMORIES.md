## Lyzr API Learnings

### Agent Updates (PUT vs PATCH)
- **PATCH is not supported** - Returns 405 Method Not Allowed
- **PUT requires ALL fields** - Missing fields cause 422 validation error
- **Solution**: Always fetch current agent first, merge updates, then PUT

### KB Connection
- KBs do NOT connect via `rag_id` field (doesn't persist)
- KBs connect via `features` array:
```json
{
  "features": [{
    "type": "rag",
    "config": {
      "knowledge_base_id": "kb-id",
      "top_k": 5
    },
    "priority": 0
  }]
}
```

### Sub-Agents
- `sub_agents` field in API request doesn't persist
- Sub-agent connections must be done in Lyzr Studio UI
- Workaround: Reference sub-agent IDs in orchestrator prompt

## Common Issues & Solutions

### "Agent not found" after creation
- Agent listing may have delay
- Solution: Use `getOrCreateAgent()` which handles conflicts

### KB not showing in agent
- Check `features` array, not `rag_id`
- Use `getAgentKnowledgeBase()` to verify

### Documents not syncing
- Check S3 permissions
- Verify document index in DynamoDB
- Check RAG service API key

## File Naming Conventions

### App Guide System (Feature Showcase)

Database-driven feature showcase / help carousel. Supports i18n.

**Apps Using Guide System:**
| App | appId | Seed Command |
|-----|-------|--------------|
| compliance-qa | `compliance-qa` | `bun run seed-guide` |
| e-learning | `e-learning` | `bun run seed-guide` |
| sales-order | `sales-order` | `bun run seed-guide` |
| customer-lifecycle | `customer-lifecycle` | `bun run seed-guide` |

**DynamoDB Table:** `tasco-app-guides`

**DB Layer** (`@tasco/db`):
```typescript
import { getAppGuide, putAppGuide, type AppGuide, type GuideSlide } from "@tasco/db";

// Get guide by app and language
const guide = await getAppGuide("compliance-qa", "en");

// Create/update guide
await putAppGuide({
  appId: "compliance-qa",
  language: "en",
  appName: "Compliance Super AI",
  appTagline: "AI-powered compliance",
  ctaText: "Get Started",
  slides: [
    { order: 0, icon: "brain", iconColor: "primary", title: "...", content: "..." }
  ]
});
```

**API Handler** (`@tasco/api`):
```typescript
import { createGuideHandler } from "@tasco/api";
const { handleGet, handlePut, handleDelete } = createGuideHandler({ appId: "my-app" });
export const GET = handleGet;
export const PUT = handlePut;
```

**UI Component** (`@tasco/ui`):
```typescript
import { GuideCarousel, GuideTrigger, useAppGuide } from "@tasco/ui";

// In component
const { guide, isOpen, setIsOpen, openGuide } = useAppGuide("my-app");

// Render
{guide && <GuideTrigger onClick={openGuide} />}
{guide && <GuideCarousel guide={guide} open={isOpen} onOpenChange={setIsOpen} />}
```

**Icons available**: sparkles, message, database, file, search, shield, chart, zap, users, globe, check, brain
**Colors available**: primary, blue, green, orange, purple, red, cyan, pink

**Adding Guide to a New App:**
1. Add `@tasco/api` to app's `package.json` dependencies
2. Create `app/api/guide/route.ts` with `createGuideHandler({ appId: "app-name" })`
3. Update header component to use `useAppGuide`, `GuideTrigger`, and `GuideCarousel`
4. Create `scripts/seed-guide.ts` with English and Vietnamese content
5. Add `"seed-guide": "bun run scripts/seed-guide.ts"` to `package.json`
6. Run `bun run seed-guide` to populate database
